# WordPress 插件重构执行手册

当收到重构指令时，请进入“外科医生模式”，执行以下标准化动作：

### 1. 结构大挪移 (Restructuring)
- **逻辑搬迁**：将硬编码在主文件或模板中的 PHP 类与函数搬迁至 `includes/`。
- **模板抽离**：将 HTML 代码段提取并封装到 `templates/` 目录的独立文件中。
- **JS/CSS 剥离**：将内联的 `<style>` 或 `style="..."` 彻底移除，并整合进 `assets/css/core.css`。

### 2. 逻辑瘦身 (De-duplication)
- **函数合并**：识别并合并功能重复的函数。
- **强制清理**：在确认新逻辑跑通后，**必须立即删除**旧的冗余方法和过时的测试代码，确保项目目录零负担。

### 3. 标准化对齐
- **前缀补全**：为所有遗漏的函数和类名统一加上 `w2p_` 前缀。
- **安全加固**：补齐所有缺少的 Nonce 校验、数据清理和输出转义逻辑。

### 4. 重构报告
重构完成后，请简洁告知：
- **移除了哪些**冗余文件/函数。
- **新增了哪些**符合规范的类或模板文件。
- **更新了哪些** CSS 类以实现样式复用。
