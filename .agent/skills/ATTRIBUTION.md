# Skills Attribution

The following WordPress skills were installed from the open-source repository
[**mralaminahamed/wp-dev-skills**](https://github.com/mralaminahamed/wp-dev-skills)
(MIT License, Copyright (c) 2026 Al Amin Ahamed), retrieved 2026-08-14.

## Installed skills

| Skill | Purpose |
|---|---|
| `wp-build-tools` | JS/CSS build pipeline for WP plugins (@wordpress/scripts, webpack, Vite, block assets) |
| `wp-plugin-audit` | Consistency + security audit (XSS / SQL injection / CSRF / nonces / capabilities / i18n) |
| `wp-coding-standards` | PHPCS + WordPress Coding Standards setup, configuration and sniff fixing |
| `wp-plugin-testing` | PHPUnit / Brain Monkey / WP_Mock / Codeception test setup and writing |
| `wp-org-submission` | WP.org directory submission, SVN deploy and reviewer-rejection fixes |
